# Geometria map

`europa-50m.geojson`: granice państw Europy i sąsiadów z Natural Earth, skala 1:50 mln (`ne_50m_admin_0_countries`, https://www.naturalearthdata.com), domena publiczna. Współrzędne zaokrąglone do 0,01°, właściwości: `iso2`, `nazwa`. Pobrane 2026-11-11 z https://github.com/nvkelso/natural-earth-vector. Granice z Natural Earth odpowiadają stanowi faktycznemu, nie stanowisku redakcji w sporach terytorialnych.

Użycie: `kartogram()` w `../wykresy.mjs`.
