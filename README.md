# Lean Time Study Tracker (VA / NVA / NNVA)

A lightweight, browser-based tool for Process Engineers and Lean Consultants to conduct time observations during Gemba walks. 

Built to replace Excel and physical stopwatches on the shop floor, it allows for real-time categorization of process steps into:
* **Value Added (VA)** - Green
* **Non-Value Added (Muda / NVA)** - Red
* **Necessary Non-Value Added (NNVA)** - Yellow

## Why I built this?
During my operational audits and Lean optimization projects, I needed a fast way to gather cycle time data and instantly visualize the waste percentage without manual data entry.
